# 服装查询

## 查服装

使用 `/查服装 <卡牌ID> [颜色位顺]` 查询指定卡牌对应的服装预览。

| 参数 | 说明 |
|---|---|
| 卡牌 ID | 必填，填写服装来源卡牌的正整数 ID，可先用[卡牌查询](/bot-help/card)查找。 |
| 颜色位顺 | 可选，从 1 开始，按该服装的颜色顺序选择；省略时使用默认颜色。 |
| 区服前缀 | 可在指令前加 `jp`、`cn`、`en`、`tw`、`kr`；省略时使用默认区服。 |

## 指令示例

- `/查服装 123`：查询卡牌 ID 123 对应服装的默认颜色。
- `/查服装 123 2`：查询该服装的第 2 个颜色。
- `/cn查服装 123 2`：在国服查询卡牌 ID 123 对应服装的第 2 个颜色。

这里的 `123` 是卡牌 ID 示例，使用时请替换为要查询的卡牌 ID。

## 查询范围

此指令只查询指定卡牌对应的服装，参数使用卡牌 ID。若该卡牌没有服装，会提示“该卡牌没有服装”；颜色位顺需在该服装实际提供的颜色范围内。
