# 服装查询

## 查服装

使用 `/查服装 <卡牌 ID> [颜色序号]` 查看卡牌对应的服装。

| 参数 | 说明 |
|---|---|
| 卡牌 ID | 必填，填写服装来源卡牌的 ID，可先用[卡牌查询](/bot-help/card)查找。 |
| 颜色序号 | 可选，从 1 开始，按服装的颜色顺序选择；不写时使用默认颜色。 |
| 区服代码 | 可在指令前加 `jp` `cn` `tw` `kr` `en`；不写时使用默认绑定的区服，没有默认绑定时使用日服(JP)。 |

## 指令示例

- `/查服装 123`：查看卡牌 ID 123 对应服装的默认颜色。
- `/查服装 123 2`：查看该服装的第 2 个颜色。
- `/cn查服装 123`：在国服(CN)查看卡牌 ID 123 对应的服装。

这里的 `123` 是卡牌 ID 示例，使用时请替换为要查询的卡牌 ID。

## 查询范围

此指令只查询指定卡牌对应的服装，参数使用卡牌 ID。卡牌没有服装时会给出提示；颜色序号需在该服装实际提供的颜色范围内。
