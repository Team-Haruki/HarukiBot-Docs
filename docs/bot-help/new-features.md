# 新功能速递

这里集中展示 HarukiBot 近期新增或刚完善的功能，方便快速了解有什么新东西可以试。

## 2026-09-13

### 查服装

- 指令：`/查服装 <卡牌ID> [颜色位顺]`
- 用法：`/查服装 123`、`/查服装 123 2`、`/cn查服装 123 2`
- 说明：查询指定卡牌对应的服装。省略颜色时使用默认颜色，颜色位顺从 1 开始；卡牌没有服装时会给出提示。
- 详细说明：[服装查询](/bot-help/costume)

### 卡牌获取时间线

- 指令：`/卡牌一览 时间`
- 用法：`/卡牌一览 时间`、`/卡牌一览 mnr 时间`、`/卡牌一览 u2 时间`
- 说明：根据已上传的 suite 数据，按真实获取时间由早到晚展示自己的卡牌，以月份为横轴、角色对应颜色为底色；缺失获取时间的卡牌单独显示。
- 详细说明：[卡牌查询：获取时间线](/bot-help/card#card-acquisition-timeline)

## 2026-8-10

### 查询背包道具

- 指令：`/道具` `/查背包` `/持有物` `/查持有物` `/背包一览` `/inventory` `/pjsk inventory`
- 用法：`/道具` `/道具 u2 火罐`
- 说明：查询指定账号背包中的道具及其数量
- 详细说明[杂项](/bot-help/misc#杂项)

## 2026-06-09

### 烤森百景 SK

- 指令：`/百景sk` `/烤森百景sk` `/mshsk` `/bjsk`
- 用法：`/bjsk 1-5`，或 `/bjsk id=25 1-5`
- 说明：查询烤森百景投稿排名线，默认使用当前正在进行的百景，展示指定名次的投稿缩略图、评价数和前后差距。支持指定 `housing_id`，一次最多查询 5 个名次，结果基于采样统计，仅供参考。
- 详细说明：[MySekai 查询](/bot-help/mysekai#查询烤森百景)

## 2026-05-23

### 自定义个人信息

- 指令：`/自定义个人信息` `/cp`
- 用法：`/自定义个人信息 1`，或 `/自定义个人信息 u2 3`
- 说明：渲染游戏公开 profile 中的自定义个人信息页，每次渲染一张。`u序号` 可选择自己绑定列表中的账号。
- 详细说明：[个人资料与账号](/bot-help/account#自定义个人信息)

### 活动规划

- 指令：`/活动规划` `/pjsk event planner` `/event-planner`
- 用法：`/活动规划 pt1000w 当前pt120w 歌 虾ex 龙hd 5火 10火`
- 说明：结合目标 PT 或目标排名、当前 PT、歌曲、火数和活动组卡结果生成规划图。需要已上传 suite 数据。
- 详细说明：[活动查询](/bot-help/event#活动规划参数)

## 2026-05-22

### 自定义谱面预览

- 指令：`/谱面预览` `/查曲` `/技能预览`
- 用法：`/jp谱面预览 <28位ID>`，或 `/jp查曲 <28位ID>`
- 说明：支持查询已发布自定义谱面的预览与详情。目前仅支持日服数据源，非日服默认绑定建议显式加 `/jp` 前缀。
- 详细说明：[音乐与乐曲](/bot-help/music#自定义谱面相关)
