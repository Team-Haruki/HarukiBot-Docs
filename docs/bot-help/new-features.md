# 新功能速递

这里集中展示 HarukiBot 近期新增或刚完善的功能，方便快速了解有什么新东西可以试。

## 2026-10-10

### 隐私设置拆分：`/隐藏id` 现在只隐藏游戏 UID

- 指令：`/隐藏id` `/显示id` `/隐藏sk` `/显示sk` `/隐藏个人信息` `/显示个人信息` `/隐藏逮捕` `/显示逮捕` `/隐藏全部` `/显示全部` `/隐私设置`
- 用法：`/隐藏sk`、`/隐藏全部 u2`、`/隐私设置`
- 说明：`/隐藏id` 现在只把回复和图片里的游戏 UID 打码显示，不再阻止其他人通过 @你 查询活动排名、个人信息和逮捕信息，这三项改用 `/隐藏sk`、`/隐藏个人信息`、`/隐藏逮捕` 分别设置。要像以前一样全部隐藏，请发送 `/隐藏全部`。之前已经隐藏的账号保持全部隐藏，新绑定的账号默认只隐藏游戏 UID；发送 `/隐私设置` 查看当前设置。
- 详细说明：[隐私设置](/bot-help/account#隐私设置)

### 新增指令写法

- 指令：`/时区` `/个人资料` `/上传背景` `/清除背景` `/调整背景` `/交换绑定` `/检查数据` `/自定义资料卡` `/开启模块化资料` `/关闭模块化资料` `/隐藏uid` `/显示uid` `/每日时速` `/玩家追踪` `/排名追踪` `/自定义房间`
- 说明：以上写法现在也可以使用，都可以加区服代码，例如 `/jp排名追踪 100`。
- 详细说明：[个人信息与账号](/bot-help/account)、[榜线与 SK](/bot-help/sk)、[音乐与歌曲](/bot-help/music#控分与歌曲排行)、[杂项](/bot-help/misc)

### 指令帮助

- 用法：`/查曲 -help`、`/组卡 -h`
- 说明：每个指令都可以在后面加 `-help` 或 `-h` 查看用法、参数和示例。
- 详细说明：[写在前面](/bot-help/#关于指令)

## 2026-09-13

### 查服装

- 指令：`/查服装 <卡牌 ID> [颜色序号]`
- 用法：`/查服装 123`、`/查服装 123 2`、`/cn查服装 123 2`
- 说明：查看卡牌对应的服装。不写颜色序号时使用默认颜色，颜色序号从 1 开始；卡牌没有服装时会给出提示。
- 详细说明：[服装查询](/bot-help/costume)

### 卡牌获取时间线

- 指令：`/卡牌一览 时间`
- 用法：`/卡牌一览 时间`、`/卡牌一览 mnr 时间`、`/卡牌一览 u2 时间`
- 说明：根据已上传的抓包数据（Suite），按真实获取时间由早到晚展示自己的卡牌，以月份为横轴、角色对应颜色为底色；缺失获取时间的卡牌单独显示。
- 详细说明：[卡牌查询：获取时间线](/bot-help/card#card-acquisition-timeline)

## 2026-08-10

### 查询背包道具

- 指令：`/查背包` `/持有物` `/查持有物` `/背包一览` `/inventory` `/pjsk inventory`
- 用法：`/查背包`、`/查背包 u2 火罐`
- 说明：查看指定账号里的道具和材料及其数量，需要抓包数据（Suite）。
- 详细说明：[杂项](/bot-help/misc#杂项)

## 2026-06-09

### 烤森百景 SK

- 指令：`/百景sk` `/烤森百景sk` `/mshsk` `/bjsk`
- 用法：`/bjsk 1-5`，或 `/bjsk id=25 1-5`
- 说明：查询烤森百景投稿排名线，默认使用当前正在进行的百景，展示指定名次的投稿缩略图、评价数和前后差距。支持指定 `housing_id`，一次最多查询 5 个名次，结果基于采样统计，仅供参考。
- 详细说明：[MySekai 查询](/bot-help/mysekai#查询烤森百景)

## 2026-05-23

### 自定义个人信息

- 指令：`/自定义个人信息` `/cp`
- 用法：`/自定义个人信息 1`，或 `/自定义个人信息 u2 3`
- 说明：生成你在游戏里设置的自定义个人信息页，每次生成一页。`u序号` 可选择自己绑定列表中的账号。
- 详细说明：[个人信息与账号](/bot-help/account#自定义个人信息)

### 活动规划

- 指令：`/活动规划` `/pjsk event planner` `/event-planner`
- 用法：`/活动规划 pt1000w 当前pt120w 虾ex 龙hd`
- 说明：结合目标 PT 或目标名次、当前 PT、歌曲、演出能量（火）和活动组卡结果生成规划图。需要抓包数据（Suite）。
- 详细说明：[活动查询](/bot-help/event#活动规划参数)

## 2026-05-22

### 自制谱面预览

- 指令：`/谱面预览` `/查曲` `/技能预览`
- 用法：`/jp谱面预览 <28 位自制谱面 ID>`，或 `/jp查曲 <28 位自制谱面 ID>`
- 说明：支持查看已发布自制谱面的谱面图与详情。自制谱面只支持日服(JP)，默认绑定不是日服(JP)的账号时请加 `jp`。
- 详细说明：[音乐与歌曲](/bot-help/music#自制谱面)
