# 个人信息与账号

> [!caution] 注意
> 
> 账号验证只支持 Haruki 工具箱快速验证。
> 
> 使用前请确认你已经在 Haruki 工具箱绑定并验证了游戏账号。
> 
> 还没有验证或绑定时，请参考[此教程](https://neo.haruki.seiunx.com/toolbox-tutorial/verify-guide)。

> [!important] /隐藏id 现在只隐藏游戏 UID
>
> `/隐藏id` 现在只把回复和图片里的游戏 UID 打码显示，不再阻止其他人通过 @你 查询活动排名、个人信息和逮捕信息。要像以前一样全部隐藏，请发送 `/隐藏全部`。
>
> 之前已经隐藏的账号保持全部隐藏，不需要重新设置。详见[隐私设置](#隐私设置)。

和账号有关的指令都可以加 `u序号` 选择自己的第几个绑定账号，例如 `u2`；不写时使用默认绑定。

## 账号绑定与切换

- `/绑定` `/pjsk bind` `/pjsk id` `/pjsk 绑定`
  - 用游戏 UID 绑定游戏账号，例如 `/绑定 1234567890123456`。区服按游戏 UID 自动识别，同一区服可以绑定多个账号，用 `u1`、`u2` 区分。
- `/绑定列表` `/pjsk绑定列表` `/pjsk bind list`
  - 查看你绑定的游戏账号和它们的序号，也可以写 `/绑定 列表`。加区服代码（如 `/jp绑定列表`）时只列出该区服的账号。
- `/绑定交换` `/交换绑定` `/pjsk绑定交换` `/pjsk bind swap`
  - 交换两个绑定账号的序号，例如 `/绑定交换 u1 u2`，也可以写 `/绑定 交换 u1 u2`。
- `/默认绑定` `/设置默认绑定` `/主账号` `/设置主账号` `/pjsk主账号` `/pjsk set main`
  - 设置默认使用的游戏账号，写 `u序号` 或游戏 UID，例如 `/默认绑定 u2`。
  - 不写区服代码时设置全局默认绑定；加区服代码（如 `/jp默认绑定 u1`）时设置该区服的默认绑定。
- `/清除默认绑定` `/取消默认绑定` `/清除主账号` `/取消主账号`
  - 不写区服代码时清除全局默认绑定；加区服代码（如 `/jp清除默认绑定`）时清除该区服的默认绑定。
- `/解绑` `/取消绑定` `/pjsk解绑` `/pjsk unbind`
  - 解除游戏账号和你的 QQ 号的绑定，写 `u序号` 或游戏 UID，例如 `/解绑 u2`。
- `/uid` `/查uid`
  - 查看自己绑定的游戏 UID，只能查看自己的账号。

## 账号验证

- `/pjsk验证` `/pjsk verify`
  - 验证绑定的游戏账号属于你，按回复的提示完成验证。<span style="color:red">部分功能需要验证后才能使用</span>，无法快速验证时请前往 Haruki 工具箱绑定。
- `/pjsk验证列表` `/pjsk验证状态` `/pjsk verify list`
  - 查看每个绑定账号是否已验证。

## 个人信息

- `/个人信息` `/个人中心` `/个人资料` `/profile`
  - 生成个人信息图：等级、称号、卡组、打歌统计等。可以写 `u序号`、`@群友` 或游戏 UID 查询指定账号，不写时查询自己的默认绑定；加 `横屏` 或 `竖屏` 指定图片方向，例如 `/个人信息 @群友`、`/jp个人信息 竖屏`。
  - 是否显示游戏 UID、能否通过 @ 查询，取决于对方的[隐私设置](#隐私设置)。
- `/开启模块化个人信息` `/开启模块化资料` `/开启模块个人信息` `/pjsk modular profile on`
  - 之后 `/个人信息` 使用模块化布局。
- `/关闭模块化个人信息` `/关闭模块化资料` `/关闭模块个人信息` `/pjsk modular profile off`
  - 之后 `/个人信息` 使用经典布局。

### 自定义个人信息

- `/自定义个人信息` `/cp` `/自定义资料卡`
  - 生成你在游戏里设置的自定义个人信息页。指令后写页码（从 1 开始），每次生成一页，例如 `/自定义个人信息 1`、`/cp 2 u2`。
  - 只能查看自己的绑定账号。

### 个人信息背景

- `/上传个人信息背景` `/上传背景` `/上传个人信息` `/上传个人背景` `/上传个人信息图片` `/pjsk upload profile bg` `/pjsk upload profile background`
  - 发送指令时在同一条消息里附带一张图片，作为这个账号的个人信息背景。需要先验证游戏账号，图片需要通过内容审核。
- `/清除个人信息背景` `/清除背景` `/清空个人信息背景` `/清除个人信息图片` `/清空个人信息图片` `/pjsk clear profile bg` `/pjsk clear profile background`
  - 删除自定义背景，恢复默认背景。
- `/调整个人信息背景` `/调整背景` `/调整个人信息` `/设置个人信息` `/设置个人信息背景` `/pjsk adjust profile` `/pjsk adjust profile bg` `/pjsk adjust profile background`
  - 调整自定义背景的方向（`横屏`、`竖屏`）、模糊程度（0~10）和透明度（0~100），例如 `/调整个人信息背景 竖屏 模糊5 透明30`。不写参数时显示当前设置。

以上设置都可以加 `u序号` 操作自己的其他绑定账号，例如 `/调整背景 u2 竖屏 模糊5 透明50`。

自定义设置会一直保留，不会因为更换图片而重置。

## 隐私设置

每个绑定账号都有下面这些设置，可以分别隐藏或显示。这些指令都可以加 `u序号` 选择账号，例如 `/隐藏sk u2`。

| 设置 | 隐藏 | 显示 | 隐藏后的效果 |
|---|---|---|---|
| 游戏 UID | `/隐藏id` | `/显示id` | 回复和图片里的游戏 UID 打码显示，不影响其他人查询 |
| 活动排名 | `/隐藏sk` | `/显示sk` | 其他人不能通过 @你 查询这个账号的活动排名 |
| 个人信息 | `/隐藏个人信息` | `/显示个人信息` | 其他人不能通过 @你 查看这个账号的个人信息，以及用这个账号的数据生成的结果（例如组卡） |
| 逮捕信息 | `/隐藏逮捕` | `/显示逮捕` | 其他人不能通过 @你 逮捕这个账号 |
| 以上四项 | `/隐藏全部` | `/显示全部` | 一次修改上面四项 |

- `/隐私设置` `/可见性设置` `/pjsk隐私设置` `/pjsk privacy`
  - 查看这个账号当前的设置，不做修改。每次修改设置后，回复里也会列出全部设置。
- 自己查询自己的账号不受这些设置影响，只有游戏 UID 按 `/隐藏id` 的设置打码。
- 新绑定的账号默认只隐藏游戏 UID，活动排名、个人信息和逮捕信息默认显示。
- `/隐藏id` 拆分之前已经隐藏的账号保持全部隐藏；想公开其中某一项，发送对应的显示指令。
- `/隐藏全部` 和 `/显示全部` 不会修改下面的[抓包显示设置](#抓包显示设置)。

这些指令的其他写法：

- `/隐藏id`：`/隐藏uid` `/pjsk隐藏id` `/pjsk hide id`
- `/显示id`：`/显示uid` `/展示id` `/pjsk显示id` `/pjsk展示id` `/pjsk show id`
- `/隐藏sk`：`/pjsk隐藏sk` `/pjsk hide sk`
- `/显示sk`：`/展示sk` `/pjsk显示sk` `/pjsk展示sk` `/pjsk show sk`
- `/隐藏个人信息`：`/pjsk隐藏个人信息` `/pjsk hide profile`
- `/显示个人信息`：`/展示个人信息` `/pjsk显示个人信息` `/pjsk展示个人信息` `/pjsk show profile`
- `/隐藏逮捕`：`/pjsk隐藏逮捕` `/pjsk hide arrest`
- `/显示逮捕`：`/展示逮捕` `/pjsk显示逮捕` `/pjsk展示逮捕` `/pjsk show arrest`
- `/隐藏全部`：`/pjsk隐藏全部` `/pjsk hide all`
- `/显示全部`：`/展示全部` `/pjsk显示全部` `/pjsk展示全部` `/pjsk show all`

## 抓包显示设置

- `/隐藏抓包` `/pjsk隐藏抓包` `/pjsk hide suite`
  - 停止使用这个账号的抓包数据（Suite）。隐藏后，需要抓包数据的指令会提示数据已隐藏。
- `/展示抓包` `/pjsk展示抓包` `/pjsk显示抓包` `/pjsk show suite`
  - 恢复使用这个账号的抓包数据。
- `/隐藏烤森抓包` `/pjsk hide mysekai`
  - 隐藏烤森抓包功能内的详细数据显示。
- `/展示烤森抓包` `/pjsk show mysekai`
  - 展示烤森抓包功能内的详细数据显示。

## 抓包状态查询

- `/抓包状态` `/抓包数据` `/抓包信息` `/检查数据` `/sud` `/pjsk抓包` `/pjsk抓包数据` `/pjsk抓包查询` `/pjsk抓包状态` `/pjsk check data`
  - 查看这个账号上传到 Haruki 工具箱的抓包数据的上传时间和是否可用。
- `/烤森抓包数据` `/msd` `/pjsk check mysekai data` `/烤森抓包`
  - 查看自己的烤森抓包数据上传时间。

## 逮捕

- `/逮捕` `/pjsk逮捕` `/pjsk arrest`
  - 查看玩家的等级、各难度 Clear/FC/AP 数量和挑战 Live 最高分。可以写 `u序号`、`@群友` 或游戏 UID，不写时查询自己的默认绑定，例如 `/逮捕 @群友`、`/jp逮捕 1234567890123456`。
  - 对方发送 `/隐藏逮捕` 后，不能再通过 @ 逮捕对方。
- `/逮捕难度` `/pjsk逮捕难度` `/pjsk arrest difficulty`
  - 设置 `/逮捕` 统计哪些难度。难度写 `easy` `normal` `hard` `expert` `master` `append`（也可以写 `hd` `ex` `apd`），开关写 `开启`、`关闭`（也可以写 `开` `关` `on` `off`），一次可以设置多个，例如 `/逮捕难度 append 开启`、`/逮捕难度 easy关 normal关`。

## 查询注册时间

- `/注册时间` `/查时间` `/pjsk 注册时间` `/pjsk reg time`
  - 查看自己的游戏账号的注册时间，只能查看自己的账号。
