# HarukiProxy V3 更新介绍

HarukiProxy V3是HarukiProxy的全新版本，2026年10月开始公开测试，**2026年11月9日发布正式版`v3.0.0`**。

> [!caution] V2已废弃
>
> **Haruki工具箱只接受V3上传的数据。** 如果你还在用V2，请尽快换成V3，V2上传的数据会被工具箱拒绝。

## V3有什么不一样

### 有界面了，不用再改配置文件

V2需要手动编辑`config.yaml`、在命令行里运行。V3是图形界面应用，所有设置都在***设置***页面里点选，首页直接显示运行状态和每类数据的捕获、上传结果。

界面支持简体中文、繁体中文和英文。

### Android、Windows、macOS都能用

- **Android**：直接安装APK，在手机上抓包。
- **Windows**：解压即用，已自带控制模拟器所需的adb。
- **macOS**：正式版新增，支持Apple芯片的Mac，配合MuMu模拟器Pro使用。

### 用工具箱账号授权上传，更安全

V3在应用里点击***连接Haruki工具箱***，在浏览器中登录并授权即可，不再使用安装包内置的共享密钥。

- 只有你在工具箱里绑定、并出现在应用账号列表中的游戏账号才会上传；登录其他账号时数据不会上传，避免误传。
- 可以选择是否在公开API中公开你上传的数据。
- 仍然支持保存到本地，以及上传到自定义端点（需要第三方服务支持V3协议）。

### 模拟器一键准备（Windows / macOS）

桌面版会自动找到MuMu模拟器并列出实例，你选择要用的实例后，HarukiProxy可以：

- 启用Root和系统盘可写，并在需要时重启实例；
- 安装抓包证书；
- 开始捕获时自动给实例设置代理，停止时自动恢复；
- 程序异常退出后，在***设置***里一键恢复残留的代理设置，模拟器不会一直连不上网。

### Android的多种抓包方式

- **VPN模式**：只接管所选游戏的流量，不影响其他应用。
- **免安装证书**：利用系统自带的eMudhra根证书，不用另外安装证书（较新的系统安全更新可能已移除相关证书，详见[免Root抓包方式](./android.india.md)）。
- **eBPF模式（实验功能）**：已Root的手机可以直接读取游戏数据，不需要VPN、代理或证书。应用被系统冻结在后台时也会照常上传。

### 上传结果看得更清楚

- 上传失败时显示具体原因和HTTP状态，例如账号未绑定、授权失效，而不是笼统的“失败”。
- MySekai生日派对投递如果没有刷新采集点，会显示“本次投递没有刷新采集点，无需上传”，不再报错。
- 数据较大或网络较慢时，上传等待时间会自动延长，不会因为固定超时而反复失败。

### 遇到问题方便反馈

设置里可以导出活动记录和诊断日志，发给维护人员排查。导出内容不包含密钥、令牌和请求正文。

## 从V2换到V3

1. 先关闭或卸载V2。Android用户可以参考[关闭HarukiProxyV2](./android.md#关闭harukiproxyv2)。
2. 按上面的表格下载V3并按对应教程设置。V2的`config.yaml`不再需要。
3. 在V3的***设置***中点击***连接Haruki工具箱***完成授权，确认要上传的账号出现在列表中。

## 目前的限制

- 由于不可抗力，不能抓取国服的MySekai数据。
- macOS版没有经过Apple公证，第一次打开前要在终端清除隔离属性，并且需要另外安装adb，详见[macOS版说明](./pc.v3.md#macos)。
- eBPF模式仍是实验功能，只支持已Root的Android设备。

## 版本记录

### v3.0.0（2026-11-09）

- 首个正式版，新增macOS版本。
- 修复Windows上连接MuMu模拟器时可能一直卡住、提示超时的问题。
- 上传超时按数据大小自动延长，网络较慢时大文件也能传完。
- MySekai生日派对投递没有刷新采集点时显示“无需上传”，不再显示为上传失败。
- 自定义上传端点误填为工具箱地址时，提示改用工具箱授权登录。
- 桌面版活动记录不再把上传被拒显示成“保存失败，请检查目录权限”。
- Android安装包体积从约14.8MB减小到约11.6MB。

### v3.0.0-beta系列（2026年10月～11月）

V3的公开测试版本，陆续加入了图形界面、工具箱授权上传、Windows桌面版、VPN模式和eBPF模式等功能。测试版已停止更新，请使用正式版。
