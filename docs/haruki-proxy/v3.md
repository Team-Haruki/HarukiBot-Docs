# HarukiProxy V3 更新介绍

HarukiProxy V3是HarukiProxy的全新版本，2026年10月开始公开测试，**2026年11月9日发布正式版`v3.0.0`**。

> [!caution] V2已废弃
>
> **Haruki工具箱只接受V3上传的数据。** 如果你还在用V2，请尽快换成V3，V2上传的数据会被工具箱拒绝。

## V3有什么不一样

### 有界面了，不用再改配置文件

V2需要手动编辑`config.yaml`、在命令行里运行。V3是图形界面应用，所有设置都在***设置***页面里点选，首页直接显示运行状态和每类数据的捕获、上传结果。

界面支持简体中文、繁体中文和英文。

### Android、Windows、macOS都能用

- **Android**：直接安装APK，在手机上抓包。
- **Windows**：解压即用，已自带控制模拟器所需的adb。
- **macOS**：正式版新增，支持Apple芯片的Mac，配合MuMu模拟器Pro使用。

### 用工具箱账号授权上传，更安全

V3在应用里点击***连接Haruki工具箱***，在浏览器中登录并授权即可，不再使用安装包内置的共享密钥。

- 只有你在工具箱里绑定、并出现在应用账号列表中的游戏账号才会上传；登录其他账号时数据不会上传，避免误传。
- 可以选择是否在公开API中公开你上传的数据。
- 仍然支持保存到本地，以及上传到自定义端点（需要第三方服务支持V3协议）。

### 模拟器一键准备（Windows / macOS）

桌面版会自动找到MuMu模拟器并列出实例，你选择要用的实例后，HarukiProxy可以：

- 启用Root和系统盘可写，并在需要时重启实例；
- 安装抓包证书；
- 开始捕获时自动给实例设置代理，停止时自动恢复；
- 程序异常退出后，在***设置***里一键恢复残留的代理设置，模拟器不会一直连不上网。

### Android的多种抓包方式

- **VPN模式**：只接管所选游戏的流量，不影响其他应用。
- **免安装证书**：利用系统自带的eMudhra根证书，不用另外安装证书（较新的系统安全更新可能已移除相关证书，详见[免Root抓包方式](./android.india.md)）。
- **eBPF模式（实验功能）**：已Root的手机可以直接读取游戏数据，不需要VPN、代理或证书。应用被系统冻结在后台时也会照常上传。

### 上传结果看得更清楚

- 上传失败时显示具体原因和HTTP状态，例如账号未绑定、授权失效，而不是笼统的“失败”。
- MySekai生日派对投递如果没有刷新采集点，会显示“本次投递没有刷新采集点，无需上传”，不再报错。
- 数据较大或网络较慢时，上传等待时间会自动延长，不会因为固定超时而反复失败。

### 遇到问题方便反馈

设置里可以导出活动记录和诊断日志，发给维护人员排查。导出内容不包含密钥、令牌和请求正文。

## 从V2换到V3

1. 先关闭或卸载V2。Android用户可以参考[关闭HarukiProxyV2](./android.md#关闭harukiproxyv2)。
2. 按上面的表格下载V3并按对应教程设置。V2的`config.yaml`不再需要。
3. 在V3的***设置***中点击***连接Haruki工具箱***完成授权，确认要上传的账号出现在列表中。

## 目前的限制

- 由于不可抗力，不能抓取国服的MySekai数据。
- macOS版没有经过Apple公证，第一次打开前要在终端清除隔离属性，并且需要另外安装adb，详见[macOS版说明](./pc.v3.md#macos)。
- eBPF模式仍是实验功能，只支持已Root的Android设备。

## 版本记录

### v3.0.0（2026-11-09）

- 首个正式版，新增macOS版本。
- 修复Windows上连接MuMu模拟器时可能一直卡住、提示超时的问题。
- 上传超时按数据大小自动延长，网络较慢时大文件也能传完。
- MySekai生日派对投递没有刷新采集点时显示“无需上传”，不再显示为上传失败。
- 自定义上传端点误填为工具箱地址时，提示改用工具箱授权登录。
- 桌面版活动记录不再把上传被拒显示成“保存失败，请检查目录权限”。
- Android安装包体积从约14.8MB减小到约11.6MB。

以下为测试版的更新记录。测试版已停止更新，请使用正式版。

### v3.0.0-beta.11（2026-11-02）

- eBPF模式开启自动上传时，由后台采集器直接上传。HarukiProxy被系统冻结在后台、甚至被清理掉时，已抓到的数据也会照常上传，切回应用后补记结果，不会重复上传。

### v3.0.0-beta.10（2026-11-02）

- 修复`v3.0.0-beta.8`、`v3.0.0-beta.9`在开启Root的光速虚拟机中打开时，整个虚拟机崩溃的问题。不支持eBPF的环境不再进行检测。
- 修复一加等ColorOS/OxygenOS手机在后台冻结HarukiProxy时，eBPF模式丢失MySekai数据的问题。

### v3.0.0-beta.9（2026-11-02）

- 修复Windows电脑上有读卡器、光驱等未就绪的盘符时，找不到MuMu模拟器、手动选择也无法使用的问题。

### v3.0.0-beta.8（2026-11-02）

- Android新增eBPF（Root）抓包方式：已Root的手机不需要VPN、代理或证书即可抓取。
- Windows安装包自带adb，不再需要另外下载adb补丁包。
- 桌面版支持Android 15的MuMu模拟器；安装证书时优先使用KernelSU模块，失败时自动换用其他方式。
- 准备MuMu模拟器的流程更稳定，adb断开后会自动重连重试。
- 桌面版活动记录会记下设备准备的每一步，方便排查问题。

### v3.0.0-beta.7（2026-10-31）

- Android新增免安装证书模式，利用系统自带的eMudhra根证书，不用另外安装证书。
- 修复VPN模式有时捕获不到数据的问题：开始捕获时会结束游戏的后台进程；检测到游戏还在使用捕获前的连接时，首页会提示重新打开游戏。
- 修复切换到系统代理模式后残留代理、导致无法再次启动的问题，设置中新增***检查并清除系统代理***。
- 台服、韩服、国服的游戏切换到备用服务器时也能正常捕获。
- 系统文件选择器无法使用的设备可以改用兼容存储目录。

### v3.0.0-beta.6（2026-10-13）

- 支持台服QooApp版。
- VPN模式改用当前网络的DNS，修复部分网络环境下游戏连不上的问题。
- 修复停止捕获时可能一直卡住的问题。

### v3.0.0-beta.5（2026-10-09）

- 界面支持简体中文、繁体中文和英文，可在***设置***中切换界面语言。
- 调整界面文案，例如主按钮改为“开始捕获数据”。

### v3.0.0-beta.4（2026-10-08）

- 断开Haruki工具箱后，界面立即恢复为“尚未连接”状态。

### v3.0.0-beta.3（2026-10-08）

- 安装包体积大幅减小，Android安装包从约32.8MB减小到约11.9MB。
- Android连接工具箱时可以一键复制授权链接。

### v3.0.0-beta.2（2026-10-08）

- 修复Android 16 + KernelSU设备上证书模块挂载失败的问题。
- Android支持用授权码方式连接Haruki工具箱，首页会引导连接工具箱。

### v3.0.0-beta.1（2026-10-06）

- V3首个测试版：全新图形界面，提供Android版和Windows桌面版。
- 通过Haruki工具箱账号授权上传数据，不再使用内置共享密钥；启动时自动加载可上传的账号。
- Android支持VPN模式和系统代理模式，支持保存到本地和自定义上传端点。
