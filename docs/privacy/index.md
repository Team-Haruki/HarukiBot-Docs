# 隐私条款

使用该 Bot，即意味着你同意[使用条款](/licence/)及隐私条款（本页）。

- Bot 接收到的所有信息只用于匹配指令，不会将消息记录保留在服务端。
- 查分等功能会显示你的游戏 UID；被人逮捕会显示你的等级、各难度的 Clear/FC/AP 数量（统计哪些难度由 `/逮捕难度` 设置）和挑战 Live 最高分。你可以在[隐私设置](/bot-help/account#隐私设置)里分别控制：
  - `/隐藏id`：回复和图片里的游戏 UID 打码显示；
  - `/隐藏sk`、`/隐藏个人信息`、`/隐藏逮捕`：不让其他人通过 @你 查询活动排名、个人信息或逮捕你的账号；
  - `/隐藏全部`：一次隐藏以上全部；`/隐私设置`：查看当前设置。
- `/隐藏id` 现在只隐藏游戏 UID。想像以前一样全部隐藏，请发送 `/隐藏全部`；之前已经隐藏的账号保持全部隐藏。新绑定的账号默认只隐藏游戏 UID。
- 所有歌曲别名、角色别名设置的日志内容将会在实时日志页面按日公示，包括设置时间、设置人 QQ 号、具体设置内容。
- 使用猜曲功能时，如果你猜对的排名达到前 20，你的昵称和 ID 会在打码中间内容后在 `排行榜` 中展示。
- 当使用者恶意破坏、恶意滥用 Bot 时，我们可能会披露使用者的个人信息。
